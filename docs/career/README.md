## Responsible Security Work

Material inherited from `professional-portfolio` has been consolidated here because it remains relevant as a professional-use statement:

- Security testing, research and automation are limited to systems owned by the author or environments with explicit authorization.
- Lab demonstrations, proofs of concept and documentation are educational and self-evaluation material; they are not claims of production SOC employment.
- The portfolio does not publish credentials, private keys, complete private transcripts or unsanitized operational artifacts.

## Evidence-Based Portfolio Standard

The portfolio deliberately separates:

- **VALIDATED** — documented controlled run with the required evidence and negative controls.
- **OBSERVED** — the artifact proves the stated telemetry, service or configuration layer only.
- **PENDING** — insufficient end-to-end evidence for a detection claim.

This standard is applied throughout the SOC HomeLab so that training activity, telemetry and validated detections are not presented as equivalent experience.
