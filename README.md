# professional-portfolio
## ⚠️ Contexto: Proyectos de Ciberseguridad (Lab Personal)

Este repositorio contiene código, scripts y documentación generados exclusivamente con **fines educativos, de investigación y autoevaluación**.

### Enfoque:
1.  **Análisis de Redes y WiFi (NetSec):** Pruebas de penetración e ingeniería inversa en mi propia infraestructura de red local.
2.  **Automatización en Seguridad (SecOps):** Scripts en Bash y Python para tareas de monitoreo, recolección de información y gestión de mi laboratorio Linux (Kali y Raspberry Pi).
3.  **Seguridad Ofensiva (Red Team Skills):** Pruebas de concepto (PoC) en entornos controlados, máquinas virtuales o plataformas con autorización explícita (p. ej., Hack The Box).
