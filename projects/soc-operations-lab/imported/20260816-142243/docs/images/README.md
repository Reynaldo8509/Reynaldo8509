# Capturas técnicas publicadas

Esta carpeta contiene 45 capturas de VirtualBox, Wazuh, WFP y Sysmon con
nombres normalizados para web. Antes de incorporarlas se respaldaron las
originales fuera del repositorio, se eliminaron metadatos y se aplicó un
cribado OCR de correos, términos de credenciales y rutas de perfil. Las
capturas con una señal sensible no se publicaron.

El [índice JSON](images_index.json) contiene rutas relativas, dimensiones,
checksums SHA-256 y el criterio de publicación de cada imagen.

Las capturas muestran exclusivamente datos del laboratorio autorizado, como
las redes privadas `192.168.56.0/24`, `192.168.57.0/24` y `10.0.2.0/24`.
